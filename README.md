# نقاط د. ميرنا - نظام نقاط الولاء للصيدليات

## 📋 نظرة عامة

نظام متكامل لإدارة نقاط الولاء للصيدليات، يتيح للمرضى إنشاء حسابات ومتابعة نقاطهم، وللإداريين إدارة المرضى ونقاطهم بشكل كامل.

## 🚀 المميزات

### للمريض:
- إنشاء حساب جديد
- تسجيل الدخول
- عرض الرصيد الحالي للنقاط
- عرض سجل المعاملات
- عرض التقدم نحو المكافأة التالية

### للأدمن:
- لوحة تحكم احترافية
- إدارة المرضى (عرض، بحث، ترقيم)
- إضافة/خصم/تعديل/تصفير النقاط
- عرض سجل معاملات كل مريض
- إحصاءات فورية (إجمالي المرضى، النقاط، عمليات اليوم، العملاء الجدد)

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية:** HTML5, CSS3, Vanilla JavaScript
- **الخادم:** Node.js, Express.js
- **قاعدة البيانات:** Firebase Firestore
- **المصادقة:** Firebase Authentication, JWT
- **النشر:** Vercel
