نظام متكامل لإدارة نقاط الولاء للصيدليات، يسمح للمرضى بتتبع نقاطهم وللمسؤولين بإدارة المرضى والنقاط بكل سهولة وأمان.

---

## 📋 نظرة عامة

**نقاط دكتور ميرنا** هو نظام إدارة ولاء متكامل مصمم خصيصاً للصيدليات. يوفر النظام واجهات منفصلة للمرضى والمسؤولين مع طبقة أمان قوية تضمن عدم تلاعب المرضى بنقاطهم.

### المميزات الرئيسية

- ✅ **مرضى**: إنشاء حساب، تسجيل دخول، عرض النقاط، تقدم المكافآت، سجل المعاملات
- ✅ **إدارة**: لوحة تحكم متكاملة، إدارة المرضى، إضافة/خصم/تعديل/تصفير النقاط
- ✅ **أمان**: JWT، كوكيز HttpOnly، مصادقة ثنائية (Firebase Auth + Admin Auth)
- ✅ **سجل معاملات**: تسجيل كل عملية نقاط مع التفاصيل الكاملة
- ✅ **تصميم احترافي**: واجهة عربية RTL، تصميم عصري للصيدليات
- ✅ **جاهز للإنتاج**: متوافق مع Vercel، متغيرات بيئة، معالجة أخطاء
